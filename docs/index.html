DataRecovery

A modern GTK4/Libadwaita application for recovering data from storage devices and disk images

Download Latest Release View on GitHub

Features

🔍 Smart File Recovery

Recover files using PhotoRec with an intuitive file type selection dialog featuring 28 categories and ~490 file types

🧩 Custom File Signatures

Define custom file signatures to recover file types that aren't in the built-in supported list

💾 Disk Imaging

Create disk images using GNU ddrescue with progress tracking and automatic error handling

📁 Auto Organization

Automatically organize recovered files by extension, with the option to keep or discard corrupted files

🔄 Duplicate Removal

Optional duplicate file detection and removal using rdfind to save space

🛡️ Safety First

Mount detection and system partition protection prevent accidental data loss

📊 SMART Data

View detailed drive health and SMART attributes to assess a disk before starting recovery

📝 Detailed Logging

Extensive logging of every recovery and imaging step for troubleshooting and review

🎨 Modern Interface

Beautiful GTK4/Libadwaita interface that follows GNOME design guidelines

Installation

openSUSE (Tumbleweed, Leap 16, Leap 15.6)

zypper addrepo https://download.opensuse.org/repositories/security:forensics/openSUSE_Tumbleweed/security:forensics.repo
zypper refresh
zypper install datarecovery

Fedora (Rawhide, 45, 44, 43)

dnf copr enable koxt2/datarecovery
dnf install datarecovery

Ubuntu (24.04 LTS, 25.10)

add-apt-repository ppa:koxt2/datarecovery
apt update
apt install datarecovery

Arch Linux

yay -S datarecovery

Debian (13 Trixie, 12 Bookworm)

echo 'deb http://download.opensuse.org/repositories/home:/koxt2:/debian/Debian_13/ /' | tee /etc/apt/sources.list.d/home:koxt2:debian.list
curl -fsSL https://download.opensuse.org/repositories/home:koxt2:debian/Debian_13/Release.key | gpg --dearmor | tee /etc/apt/trusted.gpg.d/home_koxt2_debian.gpg > /dev/null
apt update
apt install datarecovery
